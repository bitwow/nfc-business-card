# NFC-визитка Дмитрия Васильева

Статическая персональная визитка для GitHub Pages. На странице нет аналитики, рекламы, бэкенда и внешних сетевых зависимостей во время просмотра.

## Локальный запуск

```bash
npm run build
npm run serve
```

Откройте `http://localhost:4173/`.

## Изменение контактов

Все персональные данные и ссылки находятся в `data/site.js`. Пустое необязательное поле следует заменить на `null` — соответствующая кнопка не появится.

После изменений выполните:

```bash
npm run check
```

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist` с корректным URL проектного сайта и публикует его в GitHub Pages. В настройках репозитория Pages должен использовать источник **GitHub Actions**.

## NFC

В метку NTAG213 записывается только публичный HTTPS URL опубликованной страницы в виде одной NDEF URI-записи. Блокировка записи и установка пароля проектом не выполняются.
